# RU Hyphenation (Figma plugin)

Простой плагин для Figma/FigJam, который применяет переносы для **русского выделенного текста**: вставляет мягкие переносы (soft hyphen, `\u00AD`) в подходящих местах.

## Как запустить локально

1. Установить зависимости и собрать:

```bash
npm i
npm run build
```

2. В Figma: `Plugins` → `Development` → `Import plugin from manifest...` → выбрать `manifest.json` из этого репозитория.

3. Выделить текстовый слой (или фрейм/группу с текстом) и запустить плагин.

## Как это работает

- Обрабатывает все `TextNode` внутри выделения (включая вложенные).
- Для каждого слова на кириллице длиной ≥ 5 символов вычисляет точки переноса и вставляет `\u00AD`.
- `\u00AD` показывает дефис **только если слово реально разорвалось на конце строки**, и не переносится на новую строку — это и есть корректный знак переноса.
- Перед вставкой удаляет ранее добавленные символы переноса, чтобы не было дублей.

В меню плагина есть 2 команды:

- **Применить переносы (RU)**: вставляет `\u00AD` в русские слова.
- **Удалить переносы (плагина)**: удаляет все `\u00AD` (и также чистит `-\u200B`, если они остались от прошлой версии).
