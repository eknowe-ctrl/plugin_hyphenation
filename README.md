# RU Hyphenation (Figma plugin)

Простой плагин для Figma/FigJam, который применяет переносы для **русского выделенного текста**.

В Figma `\u00AD` (soft hyphen) часто не даёт видимого дефиса, поэтому есть команда, которая ставит **дефис только в реальном переносе** — но ценой того, что добавляет **явные переводы строк** (то есть переносы нужно пересчитывать после изменения ширины).

## Как запустить локально

1. Установить зависимости и собрать:

```bash
npm i
npm run build
```

2. В Figma: `Plugins` → `Development` → `Import plugin from manifest...` → выбрать `manifest.json` из этого репозитория.

3. Выделить текстовый слой (или фрейм/группу с текстом) и запустить плагин.

## Как это работает

- Обрабатывает все `TextNode` внутри выделения (включая вложенные).
- Для каждого слова на кириллице длиной ≥ 5 символов вычисляет точки переноса.
- Перед вставкой удаляет ранее добавленные символы переноса, чтобы не было дублей.

В меню плагина есть 3 команды:

- **Применить переносы с дефисом (RU) по ширине**: пересчитывает переносы по текущей ширине текстового блока и вставляет `\u2060-\n` (невидимый маркер + дефис + перевод строки) **только там, где слово реально не помещается**. Если вы поменяли ширину — запустите команду ещё раз или удалите переносы.
- Если команда ничего не изменила и в уведомлении есть `пропущено Auto width` — ваш текстовый слой в режиме **Auto width**. В этом режиме Figma не переносит строки по ширине, поэтому “дефис в конце строки” невозможен. Переключите слой на **Auto height** или фиксированную ширину и запустите команду снова.
- **Применить мягкие переносы (RU)**: вставляет `\u00AD` (правильная типографика: дефис появляется только при реальном переносе строки, но в Figma может быть не виден).
- **Удалить переносы (плагина)**: восстанавливает исходный текст (если он был сохранён плагином) или удаляет `\u2060-\n`, `\u2060-\u200B`, `-\u200B` и `\u00AD`.
