# RU Hyphenation (Figma plugin)

Простой плагин для Figma/FigJam, который применяет переносы для **русского выделенного текста**: вставляет **дефисы** в местах возможного переноса (между слогами).

## Как запустить локально

1. Установить зависимости и собрать:

```bash
npm i
npm run build
```

2. В Figma: `Plugins` → `Development` → `Import plugin from manifest...` → выбрать `manifest.json` из этого репозитория.

3. Выделить текстовый слой (или фрейм/группу с текстом) и запустить плагин.

## Как это работает

- Обрабатывает все `TextNode` внутри выделения (включая вложенные).
- Для каждого слова на кириллице длиной ≥ 5 символов вычисляет точки переноса и вставляет дефисы.
- Перед вставкой удаляет ранее добавленные символы переноса, чтобы не было дублей.

В меню плагина есть 2 команды:

- **Применить переносы (RU)**: вставляет `-\u200B` между слогами (дефис + невидимый маркер), чтобы это можно было безопасно удалить.
- **Удалить переносы (плагина)**: удаляет все `-\u200B` (и также старые `\u00AD`, если они были вставлены предыдущей версией).
