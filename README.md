# Russian Hyphenation Plugin for Figma

Простой плагин для Figma, который расставляет переносы в русском тексте.

Плагин:
- работает по выделенным текстовым слоям (или группам/фреймам с текстом);
- добавляет **мягкие переносы** (`U+00AD`) по слоговым позициям;
- при нехватке ширины в блоке Figma переносит слово и показывает дефис только в месте переноса.

## Зачем мягкий перенос

Чтобы не добавлять видимые дефисы во все слова сразу, плагин вставляет символ мягкого переноса.
В обычной строке он не виден, а на переносе отображается как дефис — это соответствует задаче для выключки по ширине.

## Установка (Development plugin)

1. Откройте Figma Desktop.
2. Перейдите в **Plugins → Development → Import plugin from manifest…**
3. Выберите файл `manifest.json` из этого репозитория.

## Использование

1. Выделите текстовый слой (или контейнер с текстовыми слоями).
2. Запустите плагин **Russian Hyphenation**.
3. Плагин автоматически обработает русский текст и покажет уведомление с результатом.

## Ограничения

- Алгоритм «несложный» и эвристический (без словаря), поэтому в редких случаях возможны неидеальные позиции переноса.
- Для текстовых слоёв с очень сложным смешанным форматированием переносы могут требовать ручной проверки.
