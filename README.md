# Russian Hyphenation Plugin for Figma

Плагин для Figma, который расставляет переносы в русском тексте по TeX-паттернам
(словарный подход, заметно точнее простой эвристики).

Плагин:
- работает по выделенным текстовым слоям (или группам/фреймам с текстом);
- ищет точки переноса по русским TeX-паттернам;
- вставляет **видимый дефис** в месте разрыва строки (через связку `-` + `U+200B`).

## Как это работает

Плагин учитывает текущую ширину текстового блока и расставляет переносы так,
чтобы дефис был видим именно в месте переноса.
При повторном запуске предыдущие переносы, добавленные плагином, автоматически пересчитываются.

## Установка (Development plugin)

1. Откройте Figma Desktop.
2. Перейдите в **Plugins → Development → Import plugin from manifest…**
3. Выберите файл `manifest.json` из этого репозитория.

## Использование

1. Выделите текстовый слой (или контейнер с текстовыми слоями).
2. Запустите плагин — откроется окно интерфейса.
3. Нажмите кнопку:
   - **Применить переносы** — расставляет переносы и включает автопересчёт при изменении ширины отслеживаемых текстовых слоёв (пока окно плагина открыто).
   - **Сбросить** — убирает переносы, добавленные плагином, и возвращает текст без них.
4. Кнопка **✕** в правом верхнем углу закрывает плагин.

## Разработка

```bash
npm install
npm run build
```

Команда `build` собирает `src/code.js` в `code.js`, который подключается в `manifest.json`.

## Ограничения

- Плагин использует шаблоны переносов, поэтому результат намного стабильнее эвристики, но отдельные редкие слова всё равно могут требовать ручной проверки.
- Автопересчёт работает только пока плагин открыт; после закрытия плагина нужно снова нажать **Применить переносы**.
- Для текстовых слоёв со смешанной типографикой (разные стили внутри одного слоя) часть слоёв может быть пропущена.
